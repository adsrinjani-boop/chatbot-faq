ChatWidget CS

Identitas & Kontak

Nama bot dan nomor WhatsApp tujuan untuk tombol eskalasi ke CS manusia.

Warna Widget

Atur warna header, tombol mengambang (floating button), dan warna aksen bubble chat pengguna.

Respon Otomatis

Pesan sambutan saat widget pertama kali dibuka, dan pesan fallback saat tidak ada FAQ yang cocok dengan pertanyaan pengguna.

Tambah FAQ Baru

FAQ muncul sebagai tombol pilihan cepat saat widget dibuka, dan juga dipakai untuk mencocokkan kata kunci saat pengunjung mengetik pertanyaan secara manual.

Widget akan mencocokkan kata kunci ini dengan pesan yang diketik pengunjung untuk menampilkan jawaban otomatis.

Zona Berbahaya

Menghapus seluruh chat logs dan semua foto di storage chat-media secara permanen.

Bot ID Anda

ID unik akun Anda. Setiap widget yang dipasang dengan Bot ID ini akan menampilkan FAQ, pengaturan, dan mencatat chat log khusus milik akun Anda saja (isolasi data multi-tenant).

Script Embed

Copy kode ini, lalu paste sebelum </body> di website manapun. Bot ID sudah otomatis tertaut ke akun Anda, jadi nama bot, warna, FAQ, dan pesan sudah sesuai Pengaturan Widget Anda.

Download File Langsung

Unduh file widget untuk di-hosting sendiri, beserta contoh HTML siap pakai.

Download widget.js

File index.html yang diunduh sudah berisi kode embed dengan URL hosting ini — tinggal upload berdua dengan widget.js.

Konfigurasi Lanjutan (Opsional)

WAKTU SESI DARI PESAN FOTO AKSI

⚠️ Perlu Tabel faq_data di Supabase

Jalankan SQL berikut sekali saja di Supabase Dashboard → SQL Editor sebelum memakai fitur ini (aman dijalankan meski tabel sudah ada — pakai IF NOT EXISTS). 

create table if not exists public.faq_data (
  id bigint generated always as identity primary key,
  question text not null,
  answer text not null,
  created_at timestamptz not null default now()
);

alter table public.faq_data enable row level security;

create policy if not exists "faq_public_read" on public.faq_data
  for select using (true);

create policy if not exists "faq_admin_write" on public.faq_data
  for all using (auth.role() = 'authenticated') with check (auth.role() = 'authenticated');

PERTANYAAN JAWABAN AKSI

⚠️ Langkah 1 — Matikan Verifikasi Email (WAJIB)

Agar pendaftaran admin bisa pakai email dummy tanpa verifikasi:
Supabase Dashboard → Authentication → Sign In / Providers → Email → matikan "Confirm email" → Save.
Tanpa ini, pendaftaran akan gagal kena email rate limit / diminta verifikasi. Catatan: domain email harus tetap terlihat valid (mis. @gmail.com) — domain example.com ditolak Supabase.

Langkah 2 — Jalankan SQL Ini

Copy-paste ke Supabase Dashboard → SQL Editor → New query → Run. Membuat tabel chat_logs, RLS policy (READ/INSERT/DELETE), dan bucket Storage chat-media. 

Memuat supabase-setup.sql ...
⬇️ Download supabase-setup.sql

Langkah 3 — Tes

  1. Buka example.html, kirim pesan & foto dari widget.
  2. Kembali ke sini, buka tab Activity & Logs — pesan harus muncul.
  3. Pasang kode embed di website Anda. Selesai! 🎉

Catatan keamanan: setiap akun yang terdaftar di aplikasi ini bisa membaca & menghapus semua log. Untuk multi-admin yang lebih ketat, batasi policy admin_read/admin_delete ke email/user id tertentu.
